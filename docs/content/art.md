# 아트 (픽셀아트)

최종 수정: 2026-10-14 · 게임 버전 0.1.0

게임 안의 그림은 모두 PixelLab 으로 만든 픽셀아트다. 글자(로고 글씨, 본문)와 UI 틀(카드, 버튼, 아바타 원)은 브랜드 폰트·CSS 그대로다.

## 팔레트

브랜드 색에 맞춰 생성할 때 아래 8색으로 고정했다(PixelLab `color_image` 강제 팔레트).

| 색 | 쓰임 |
| --- | --- |
| `#111111` `#2B2B2B` | 윤곽선, 폭탄 몸통, 단색 아이콘 |
| `#78FF3B` `#4CC01E` `#B9FF8F` | 라임: 불꽃, 펑 터짐, 로고 화살표 |
| `#FAF9F3` `#D9D9D9` `#8A8A8A` | 하이라이트, 금속 마개 |

## 표시 규칙

- 확대할 때 `image-rendering: pixelated` 로 픽셀을 살린다 (`.pixel` 클래스).
- 아이콘과 왕관은 어두운 픽셀만 남긴 단색 실루엣이다. `PixelIcon` 이 CSS mask 로 글자색을 입혀서, 밝은 화면에선 검정, 라이어의 어두운 화면에선 아이보리로 보인다.
- 폭탄 위 숫자(`??`, 남은 초)는 그림이 아니라 글자다. 위치는 폭탄 몸통 중심(가로 45%, 세로 67%).

## PixelLab 생성 기록

모두 `create_image_pixflux`, 배경 투명, 위 팔레트 강제. 1장당 1 generation, 총 9회 사용(폭탄·번개는 한 번씩 다시 생성).
