# NUNCHUP 기획서

최종 수정: 2026-10-14 · 게임 버전 0.1.0

## 개요

공용 스크린 없이 각자의 스마트폰으로 접속해 룸 코드 하나로 3~8명이 함께 노는 실시간 모바일 소셜 파티 게임.
배포 주소: https://kiliuswook.github.io/nunchup/ (P2P 모드)

## 핵심 루프

홈 → 룸 생성/참가 → 방장이 게임 선택 → 라운드 진행 → 결과 공개(점수 변화 + 그날의 누적 순위) → 다음 게임

## 게임 목록

규칙과 수치는 `README.md` 의 "포함된 기능" 표와 `server/src/games/` 코드가 기준이다. 이름·설명 문구는 `client/src/gamesMeta.js`.

| 게임 | 종류 | 요약 |
| --- | --- | --- |
| 눈치 카운트 | 눈치 & 타이밍 | 숫자를 하나씩 겹치지 않게 탭. 3라운드 |
| 소수파 생존 | 심리 & 예측 | 양자택일에서 적은 쪽만 생존. 5라운드 |
| 라이어 키워드 | 블러핑 & 배신 | 제시어를 모르는 라이어 찾기 |
| 시한폭탄 | 반응 & 순발력 | 언제 터질지 모르는 폭탄 넘기기. 3라운드 |

## 시스템

- 멀티플레이: 서버 모드(Node + Socket.IO)와 P2P 모드(방장 브라우저가 서버, PeerJS). 차이는 `README.md` "두 가지 실행 방식".
- 플레이어 신분은 브라우저 localStorage 토큰으로 구분한다. 같은 브라우저의 탭들은 같은 플레이어가 된다.
