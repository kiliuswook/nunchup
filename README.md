# NUNCHUP

> Read the room. Play the moment.
> 모바일 소셜 파티 게임 — 컨셉 기획서 v1.1 기준 MVP

공용 스크린 없이 각자의 스마트폰으로 접속해서, 룸 코드 하나로 3~8명이 바로 함께 노는 실시간 파티 게임입니다.

## 포함된 기능 (MVP 범위)

| 기획서 항목 | 구현 |
| --- | --- |
| 공통 구조 | 홈 → 룸 생성/참가 → 게임 선택 → 라운드 진행 → 결과 공개 → 다음 게임 |
| 빠른 입장 | 파티 시작(비공개 룸), 방 참가(4자리 코드 / 초대 링크 `?code=XXXX`), 빠른 시작(공개 대기방 자동 매칭) |
| 멀티플레이 | 3~8인, 서버 기준 입력 판정, 새로고침·끊김 후 자동 재접속, 방장 자동 승계 |
| 결과/점수 | 게임별 점수 변화 + 그날의 누적 순위 |
| 게임 01 눈치 & 타이밍 | **눈치 카운트**: 1부터 한 번씩 탭. 0.6초 안에 겹치면 충돌(-1), 끝까지 못 누른 사람 -1, 숫자를 지킨 사람 +1. 3라운드 |
| 게임 02 심리 & 예측 | **소수파 생존**: 양자택일 질문 카드, 더 적은 쪽만 생존(+1). 결과 분포와 생존자 공개. 5라운드 |
| 게임 03 블러핑 & 배신 | **라이어 키워드**: 역할 확인 → 토론 → 투표 → (지목되면 라이어의 제시어 추리) → 정체 공개 |
| 게임 04 반응 & 순발력 | **시한폭탄**: 폭발 시각은 비밀, 마지막 5초만 공개. 받은 폭탄은 1초 뒤에 넘길 수 있음. 터질 때 든 사람 -1. 3라운드 |
| 브랜드 | 블랙 #111111 · 아이보리 #FAF9F3 · 라임 #78FF3B · 그레이 #D9D9D9, Satoshi(영문) + Pretendard(국문), 세로형 모바일 UI |

화면 예시는 `docs/` 폴더의 스크린샷을 참고하세요.

## 두 가지 실행 방식

| | 서버 모드 (기본) | P2P 모드 (GitHub Pages) |
| --- | --- | --- |
| 게임 서버 | Node 서버 (`server/`) | 방장의 브라우저 |
| 필요한 것 | Node 서버 호스팅 | 정적 호스팅만 (GitHub Pages) |
| 빠른 시작 | 지원 | 미지원 (공개방 목록이 없음) |
| 방장이 나가면 | 다른 사람이 방장 승계 | 방이 종료됨 |

게임 규칙과 룸 로직(`server/src/rooms.js`, `games/`)은 두 방식이 그대로 공유합니다. P2P 모드는 `server/src/hub.js`를 브라우저에서 실행하고, PeerJS(WebRTC 데이터 채널)로 참가자를 연결합니다. 연결 중계(시그널링)는 기본으로 PeerJS 공용 서버를 쓰고, `VITE_PEER_HOST` 등으로 직접 운영하는 서버를 지정할 수 있습니다.

### GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 테스트 → P2P 빌드 → Pages 배포를 자동으로 합니다. 처음 한 번은 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 지정해야 합니다.

로컬에서 P2P 빌드 확인: `VITE_P2P=1 npm run build` 후 `client/dist`를 아무 정적 서버로 열면 됩니다.

> 방장 휴대폰의 화면이 꺼지거나 앱이 백그라운드로 가면 브라우저가 타이머를 늦춰 게임 진행이 멈출 수 있습니다. 방장은 화면을 켜 둔 채로 플레이하세요.

## 기술 스택

- **서버**: Node.js 22, Express, Socket.IO — 룸/게임 상태와 모든 판정을 서버가 가집니다.
- **클라이언트**: React 18 + Vite — 모바일 웹(PWA 형태 확장 가능). 빌드하면 서버가 정적 파일로 함께 서빙합니다.
- **테스트**: `node:test` + 가짜 시계로 게임 규칙 단위 테스트.

## 실행

```bash
npm install

# 개발: 서버(3001) + Vite(5173, /socket.io 프록시)
npm run dev
# 휴대폰에서 같은 와이파이로 http://<내 PC IP>:5173 접속

# 배포용: 클라이언트 빌드 후 서버 하나로 실행
npm run build
npm start            # http://localhost:3001

# 테스트
npm test
```

Docker: `docker build -t nunchup . && docker run -p 3001:3001 nunchup`

환경 변수: `PORT`(기본 3001), `MIN_PLAYERS`(기본 3, 혼자 테스트할 때 1로).

## 구조

```
server/src/
  index.js          Socket.IO 이벤트 ↔ RoomManager 연결, 플레이어별 상태 전송
  rooms.js          룸 생성/참가/빠른 시작/재접속, 방장, 점수 누적
  games/base.js     공통 게임 기반 (타이머, 참가자 고정, 점수)
  games/nunchi.js   눈치 카운트
  games/minority.js 소수파 생존
  games/liar.js     라이어 키워드
  games/bomb.js     시한폭탄
  data/             질문 카드, 라이어 제시어
client/src/
  net.js            소켓 연결, 세션 토큰(localStorage), 서버 시계 보정
  screens/          홈, 로비(파티 룸), 결과
  games/            게임별 화면
  styles.css        브랜드 시스템
```

새 게임은 `BaseGame`을 상속해 `start / action / view`를 구현하고 `games/index.js`와 클라이언트 `App.jsx`에 등록하면 됩니다.
